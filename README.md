## ⚙️ TECH STACK

No React. No build step. No `node_modules`. Just the fundamentals, done deliberately.

```
HTML5  ·  CSS3 (custom properties, grid, color-mix)  ·  Vanilla JavaScript
Three.js r128  →  custom wireframe emblems (arc reactor, shield, fist, web, hammer)
Google Fonts   →  Bebas Neue / Inter / JetBrains Mono
```

Every Avenger emblem in the background of each section is an **original wireframe build** —
not a logo lift — assembled from primitive geometries (torus, box, cylinder, extrude) and
rotated live via `requestAnimationFrame`. Respects `prefers-reduced-motion`.
